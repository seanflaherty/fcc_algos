# freeCodeCamp Python Algorithms (`fcc_algos`)

> A clean, documented repository featuring solutions and implementations for algorithms and data structure challenges from [freeCodeCamp](https://www.freecodecamp.org/) Python certification.

## 📌 About The Project

This repository serves as a practical practice workspace for mastering fundamental algorithms, data structures, and computational problem-solving in Python.

The implementations focus on:
* **Clarity & Readability:** Clean, well-structured Python code following standard conventions.
* **Algorithmic Efficiency:** Optimal time and space complexity solutions.
* **Core Concepts:** Recursion, sorting, searching, string manipulation, and foundational data structures.

---

## 📂 Featured Topics & Categories

* **Basic Algorithmic Scripting:** String reversal, factorials, palindrome checking, title casing.
* **Intermediate Algorithms:** Difference of arrays, search and replace, HTML entity converting, sum all primes.
* **Data Structures:** Lists, dictionaries, hash tables, stacks, queues, and tree traversals.
* **Optimization & Math:** Greatest Common Divisors (GCD), Least Common Multiples (LCM), and number theory challenges.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Python 3.8 or higher** installed on your system.

```bash
python3 --version
```

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/seanflaherty/fcc_algos.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd fcc_algos
   ```

---

## 💡 Usage & Running Tests

Each algorithm script is self-contained. You can execute any individual algorithm script directly from your terminal:

```bash
python3 path/to/algorithm_file.py
```

If the repository includes unit tests (e.g., using Python's built-in `unittest` module or `pytest`), run:

```bash
# Using Python's built-in test runner
python3 -m unittest discover

# Or using pytest (if installed)
pytest
```
